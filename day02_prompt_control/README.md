## Day 02 – Prompt Control & Interview Question Generator

### What I built
- A reusable LLM utility for structured JSON output
- A role-based interview question generator
- Controlled difficulty using prompt engineering and temperature

### Key Concepts Used
- System vs User prompts
- Role-based prompting
- Deterministic vs creative output
- JSON validation and markdown stripping

### Why this matters
This project demonstrates how to safely integrate LLMs into applications by controlling behavior, enforcing structure, and validating outputs before use.
