### System vs User Prompt
- System prompt defines rules and behavior
- User prompt provides task-specific input

### Role-Based Prompting
- Assigning roles improves depth and realism
- Used FAANG interviewer role to simulate real interviews

### Why JSON Validation is Required
- LLM output is probabilistic and untrusted
- Must validate format and schema before using in code

### Engineering Mindset
Treat LLM output like external API or user input — always validate before use.
